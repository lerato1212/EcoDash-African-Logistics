ECODASH- AFRICAN LOGISTICS SIMULATION
Project Description: EcoDash is an interactive HTML5 Canvas simulation that explores sustainable logistics within an African environment. The player operates a solar-powered electric delivery vehicle and must transport essential supplies to different destinations while managing limited battery power, environmental conditions, infrastructure challenges and delivery time limits. The simulation is designed to display how digital technology solutions can be used to explore real-world logistic challenges. Players will need to plan routes, manage resources, avoid obstacles and respond to changing environmental and infrastructure conditions.

Technologies: HTML5, CSS3, Vanilla JavaScript, GitHub

Planned features: Interactive HTML5 Canvas environment, player-controlled delivery vehicle, delivery missions, battery management, load-shedding challenges, score system, time-based missions, African-inspired environments, obstacles and collision detection

Installation instructions: Download this repository
Open the project folder in Visual Studio
Open the project using a local development server
Open index.html in the browser through the local development server
Use the keyboard controls provided in the game to interact with the simulation.
