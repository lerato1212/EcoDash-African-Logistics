## Reflection

AI has helped me with planning, understanding programming concepts and organising my project. I did not use AI as a replacement for understanding the work. I will test the code myself and make changes when something does not work as expected.

For example, the AI suggested using vectors for movement. I need to understand that the x and y values represent the direction and movement of the vehicle before using the concept in my code.

I will continue recording AI assistance throughout development and explain any important changes I make to AI-generated suggestions.
